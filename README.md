# Nature's Sirens: How Many Warnings Will It Take for Humanity to Act? 🌍🔥

[![R](https://img.shields.io/badge/R-4.5%2B-blue?logo=r&logoColor=white)](https://www.r-project.org/)
[![RMarkdown](https://img.shields.io/badge/RMarkdown-HTML-orange?logo=markdown&logoColor=white)](https://rmarkdown.rstudio.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An interactive web report and data storytelling project developed for **RMIT University**. This project investigates the widening gap between Earth's biophysical warning signals (**NOAA Surface Temperature Anomalies**) and human socio-economic vulnerability (**EM-DAT Natural Disaster Records**).

---

## 📊 Key Visualisations Included
1. **Multivariate Macro Trend:** Dual-axis visualization tracking extreme weather escalation alongside global temperature anomalies ($^\circ\text{C}$).
2. **Global Spatial Mapping:** Interactive geospatial distribution of cumulative disaster events across global jurisdictions.
3. **The Biophysical Siren:** Core hypothesis scatter plot linking thermal anomalies to disaster frequency and population displacement.
4. **Multivariate Impact Bubble Chart:** Analyzing populations affected versus financial reconstruction costs ($USD billions).
5. **The Inaction Paradox:** Cumulative area chart illustrating the compounding financial cost of delayed global climate adaptation.

---
